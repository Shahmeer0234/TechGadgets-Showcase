# ⚡ TechGadgets Showcase Page

A responsive and modern e-commerce product showcase landing page built using **HTML5**, **Custom CSS3**, and **Bootstrap 5**.

---

## 🚀 Live Features

- **📱 Fully Responsive Design:** Clean layout optimized for mobile, tablet, and desktop screens using Bootstrap's flex/grid system.
- **🛍️ Product Display:** Card-based UI showing 5 featured tech products with image cover fitting.
- **🏷️ Badges & Overlay Tags:** Dynamic badges (`Hot`, `New`, `Sale 15%`) positioned over product cards.
- **📊 Interactive Price List:** Responsive table layout displaying pricing breakdowns.
- **❓ Collapsible FAQ Section:** Built using Bootstrap's JavaScript Accordion component.
- **🎨 Custom Styling:** Smooth hover animations and custom CSS variables.

---

## 🛠️ Tech Stack

- **HTML5** - Page structure & semantic components
- **CSS3** - Custom hover effects & gradient backgrounds
- **Bootstrap 5** - Responsive grid, navbar, cards, badges, and JavaScript accordion
